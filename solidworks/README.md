# SOLIDWORKS
## Please Note
The `*.SLDASM` and `*.SLDPRT` design files here were created with
[SOLIDWORKS 2026 under the Makers license](https://www.solidworks.com/solution/solidworks-makers).
For that reason, they *cannot be used for commercial purposes*.

## Overview

These files contain the design of the 3d-printed pieces of this project.
* `SolarDaisy 2026.SLDASM` is the main assembly showing all parts
* `SolarDaisyFace 2026.SLDPRT` (for 3d printing) is the transparent front face of the light, which looks like a six-petal daisy
* `SolarDaisyBack 2026.SLDPRT` (for 3d printing) is the backplate that helps seal the daisy face and connect to the rest of the structure; for 3d printing
* `(To be provided)` (for 3d printing)
   connects the Solar Daisy backplate to the rest of the structure of the light,
   principally the stake post and solar panel/battery compartment
* `MainBoard.SLDPRT` is the main body of the PCB, exported from KiCad for reference
* `BreakawayBoard.SLDPRT` is a breakaway portion of the PCB that resides with the solar panel and battery in a part not yet shown
* `solar-light-charlie-boost.step` is a STEP file of the PCB exported from KiCad
* `solar-light-charlie-boost.SLDPRT` is a SOLIDWORKS part created from the STEP file above, used to create `MainBoard.SLDPRT` and `BreakawayBoard.SLDPRT`
