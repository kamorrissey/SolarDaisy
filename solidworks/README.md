# SOLIDWORKS

The `*.SLDASM` and `*.SLDPRT` design files here were created with
[SOLIDWORKS 2026 under the Makers license](https://www.solidworks.com/solution/solidworks-makers).
For that reason, they *cannot be used for commercial purposes*.

## Overview

These files contain the design of the 3d-printed pieces of this project.
* `SolarDaisy 2026.SLDASM` - the main assembly showing all parts
* `SolarDaisyFace 2026.SLDPRT` -
   The transparent front face of the light, which looks like a six-petal daisy; for 3d printing
* `SolarDaisyBack 2026.SLDPRT` - backplate that helps seal the daisy face and connect to the rest of the structure; for 3d printing
* `MainBoard.SLDPRT` - main body of the PCB, exported from KiCad for reference
* `BreakawayBoard.SLDPRT` - breakaway portion of the PCB that resides with the solar panel and battery in a part not yet shown
* `solar-light-charlie-boost.step` - STEP file of manufactured PCB exported from KiCad
* solar-light-charlie-boost.SLDPRT - SOLIDWORKS part created from STEP file above, used to create `MainBoard.SLDPRT` and `BreakawayBoard.SLDPRT`
